Windows x64 media runtime

The Flutter media_kit and media_kit_video integration remains MIT licensed.
Windows x64 uses the baseline x86-64 full libmpv build below, including FFmpeg's
PGS bitmap subtitle decoder. No x86-64-v3 CPU requirement is introduced.

corresponding source for distributed binaries under their applicable licenses.
mpv's copyright, GPLv2 and FFmpeg's GPLv3 texts accompany the runtime in the

The verified development archive is kept at native/third_party in this project's
source to preserve clean builds after the upstream rolling release is removed.
That archive contains binaries and API headers, not complete component source.

ANGLE remains v1.0.1 from:
https://github.com/alexmercerind/flutter-windows-ANGLE-OpenGL-ES/tree/v1.0.1
Vulkan loader is supplied by that verified ANGLE distribution and is bundled
alongside libmpv; libmpv imports it even when rendering through ANGLE.
Vulkan loader source: https://github.com/KhronosGroup/Vulkan-Loader

Android and Windows ARM64 keep their existing native runtime versions.
