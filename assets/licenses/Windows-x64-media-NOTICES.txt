Windows x64 media runtime

The Flutter media_kit and media_kit_video integration remains MIT licensed.
Windows x64 bundles the compact media-kit 20241021 runtime. Users can install
the optional baseline x86-64 full build below for PGS bitmap subtitle decoding.
No x86-64-v3 CPU requirement is introduced. Installed components are retained in
the application support directory independently of application updates.

https://github.com/alexmercerind/flutter-windows-ANGLE-OpenGL-ES/tree/v1.0.1

alongside libmpv; libmpv imports it even when rendering through ANGLE.
