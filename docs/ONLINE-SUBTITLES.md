# 在线字幕

在内置播放器打开“播放设置 → 字幕 → 在线字幕”。电视播放器也可从字幕入口进入。面板打开后按当前视频文件名搜索，保留集数与片源版本；结果不合适时可修改视频名称并重新搜索。

使用迅雷接口 `https://api-shoulei-ssl.xunlei.com/oracle/subtitle?name=视频名字`，查询参数自动编码。按接口顺序显示结果，去掉重复下载地址及不支持的格式；显示字幕名称、语言、SRT/VTT/ASS/SSA 格式和接口提供的字幕时长。短名称可能匹配多个作品，需自行选择对应作品和集数。

点击结果后下载最多 8 MB 的字幕副本，UTF-8、UTF-16 与 GBK 字幕在后台统一为 UTF-8，保留 ASS 样式与时间轴；成功后载入并关闭面板。可在原字幕菜单关闭、切换或校正时间；选中的字幕沿用现有 DLNA 字幕转换与发送流程，电视能否显示由接收设备决定。在线查询不自动替换当前字幕，也不改变同目录字幕的自动匹配。

本地导入和同目录网盘字幕复用 `SubtitleFiles` 的同一套编码处理：支持 UTF-8（含 BOM）、UTF-16 LE/BE（含 BOM，或具有明确 ASCII 时间轴特征的无 BOM 文件）及 GBK，转换在独立 isolate 中执行。原文件保持不变，播放器只读取缓存目录中的 UTF-8 私有副本；输入和转换后的内容均限制 8 MB。编码不完整、错误网页、JSON 或没有字幕时间轴的内容会返回错误，不作为已加载字幕保存。

同目录网盘字幕使用所选字幕自己的文件 ID、分享凭证和账号请求头下载。手动选择成功后显示已加载提示；下载、编码或原生 `sub-add` 失败时显示可重试的字幕错误，继续播放当前视频，自动匹配失败保持静默。重复失败仍显示提示，重试成功替换失败提示。切换集数、选择其他字幕或账号变化会取消旧请求，迟到的私有副本清理后不载入。

搜索和下载使用独立网络客户端，不继承网盘凭据及视频请求头。查询只使用文件名或输入的名称；搜索词不写入历史。搜索结果为面板内临时状态，切换视频、启动投屏或关闭面板会取消请求，迟到的文件不会载入其他视频。载入后的私有副本由播放器管理，原生读取结束后清理。

Windows 上的字幕搜索和 CDN 下载复用现有系统代理适配器，读取当前用户的手动代理、绕过列表及 PAC 设置；没有系统代理时沿用原来的环境代理。明确的绕过列表和 PAC 返回的直连结果优先于环境代理。字幕客户端独立配置，不改变其他网盘的下载路由。本机和局域网 IP 地址直连。代理切换使用独立连接池，重定向保留请求自己的 User-Agent；配置了代理时，不因为失败自行绕过它。

搜索和字幕下载遇到短暂连接中断、超时或可恢复 HTTP 状态时，最多自动重试一次，通常等待 2 秒；短 Retry-After 按服务要求等待，超过 5 秒时交给稍后的手动重试。空结果、异常 JSON、过期下载地址、证书校验和代理配置错误不会自动反复请求。下载流中断后重新下载独立副本，不把残缺内容拼接到新文件；关闭面板或切换视频会取消请求及重试等待。

错误提示区分搜索与下载，以及 DNS 解析、超时、证书、代理和服务 HTTP 状态。日志记录失败阶段、网络错误类别、底层类型和数字错误码，保留搜索失败与下载/原生载入失败的区别；不记录搜索名称、完整下载地址、代理地址或凭据。

空结果可修改名称重新搜索，网络或服务错误可重试；下载失败保留结果供重新选择。接口不返回支持格式时显示空结果，不将压缩包或 HTML 错误页作为字幕载入。

搜索框和结果采用同一滚动布局，键盘弹出、收起和横屏空间变小时保留输入焦点与中文组合输入，结果按需创建；键盘不会因布局切换自动收起。输入框沿用播放器的深色圆角配色，亮色和深色主界面下均保持一致，聚焦时标签浮动并使用主题强调色。
