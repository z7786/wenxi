# 在线字幕

在内置播放器打开“播放设置 → 字幕 → 在线字幕”。电视播放器也可从字幕入口进入。面板打开后按当前视频文件名搜索，保留集数与片源版本；结果不合适时可修改视频名称并重新搜索。

使用迅雷接口 `https://api-shoulei-ssl.xunlei.com/oracle/subtitle?name=视频名字`，查询参数自动编码。按接口顺序显示结果，去掉重复下载地址及不支持的格式；显示字幕名称、语言、SRT/VTT/ASS/SSA 格式和接口提供的字幕时长。短名称可能匹配多个作品，需自行选择对应作品和集数。

点击结果后下载最多 8 MB 的字幕副本，UTF-8、UTF-16 与 GBK 字幕在后台统一为 UTF-8，保留 ASS 样式与时间轴；成功后载入并关闭面板。可在原字幕菜单关闭、切换或校正时间；选中的字幕沿用现有 DLNA 字幕转换与发送流程，电视能否显示由接收设备决定。在线查询不自动替换当前字幕，也不改变同目录字幕的自动匹配。

搜索和下载使用独立网络客户端，不继承网盘凭据及视频请求头。查询只使用文件名或输入的名称；搜索词不写入历史。搜索结果为面板内临时状态，切换视频、启动投屏或关闭面板会取消请求，迟到的文件不会载入其他视频。载入后的私有副本由播放器管理，原生读取结束后清理。

空结果可修改名称重新搜索，网络或服务错误可重试；下载失败保留结果供重新选择。接口不返回支持格式时显示空结果，不将压缩包或 HTML 错误页作为字幕载入。

搜索框和结果采用同一滚动布局，键盘弹出、收起和横屏空间变小时保留输入焦点与中文组合输入，结果按需创建；键盘不会因布局切换自动收起。输入框沿用播放器的深色圆角配色，亮色和深色主界面下均保持一致，聚焦时标签浮动并使用主题强调色。
