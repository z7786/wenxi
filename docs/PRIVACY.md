# 隐私与网络访问

文析助手直接与用户选择的网盘服务通信。网盘登录、文件列表、上传、下载和播放会向对应服务发送操作必需的凭据和参数；这些服务的隐私政策与账号限制也适用。

资源搜索会从构建者配置的后台获取已签名的公开搜索规则与插件模块，使用用户设备网络向对应搜索站点和 Telegram 公开频道提交关键词。后台补搜只提交关键词及来源 ID。规则与最近结果保存在本地加密状态中，后台不可达时复用缓存。设备搜索的网页会话使用独立存储，与网盘登录会话分开；不向搜索源发送网盘账号凭据。用户打开某个文件预览时，号池服务可能收到该公开分享链接、提取码、标题和所选文件的 ID、名称、大小，以及本地随机客户端标识，用于单文件转存与排行统计；后台不可达时使用原链接预览。

阿里视频播放通过 [OpenList 授权服务](https://api.oplist.org/alicloud/requests) 获取 OAuth 参数，在阿里官方授权端点使用当前账号的普通登录 Token 完成授权，再向 `api.oplist.org/alicloud/callback` 提交一次性授权码，由该服务换取阿里开放平台 Token。OpenList 在换取过程中会处理该授权码与开放平台凭据；普通登录 Token 和账号密码不发送给 OpenList。授权范围包含账号基本信息及文件读写，分享视频会先转存到当前账号资源库中的独立临时目录。开放平台凭据按账号保存在现有本地加密存储中，到期后通过当前账号重新授权。播放地址由阿里官方开放接口返回，视频由客户端直接连接阿里媒体地址或经本机播放代理读取；使用结束后复用既有临时目录清理流程。

百度视频播放和账号视频下载使用同一内置接口，个人视频直接向百度请求播放地址，登录后的分享视频向百度验证提取码、读取当前账号 UID 并获取免转存播放地址。请求所需的账号 Cookie、分享凭证和视频标识只发给百度；播放链接与请求凭证不跨账号缓存。播放器和下载器使用百度返回的临时地址读取视频，地址失效时重新取链。视频不请求中转取链服务，播放器的下载按钮重新获取媒体地址。明确选择公益解析的分享下载保留其独立通道。未登录的公益分享播放继续使用所选公益解析通道。

百度个人网盘，以及分享页选择“账号下载”后的非视频文件下载，优先将当前用户的必要登录凭据、文件标识和客户端参数加密发送到构建者配置的取链服务。服务通过云电脑工作节点，使用该用户自己的账号向百度请求下载地址；队列只短时保存加密任务，完成或超时后删除，不长期保存账号凭据，不记录 Cookie、文件路径和完整下载链接。中转取链或下载地址检查失败后，App 使用内置预览接口直接向百度提交当前账号和文件参数，不再请求服务器预览入口。文件内容始终由客户端直接连接百度读取，不经过中转服务或工作节点。未配置中转服务时直接使用内置预览。旧 App 的原线上预览入口继续保留。

百度分享链接默认使用“公益解析”，会向 [mf.dg22.top](https://mf.dg22.top) 发送所选分享链接、提取码、分享文件标识和解析密码，用于列出文件并获取下载地址；不会向该站发送用户的百度账号 Cookie、Token 或账号密码。每天首次打开或跨天返回应用时，会在后台读取配置的语雀公开文档，提取最新 UC 口令，以游客身份获取对应文本，只读取文件开头并提取第一行的中文作为解析密码。密码按北京时间每日更新，在本地加密缓存；当天成功更新后复用缓存，密码被拒绝时会重新拉取。主来源不可用或密码被拒绝时，尝试从构建者配置的 Gitee 文本地址获取备用密码；重试次数有上限，后台更新失败不阻止应用启动。密码更新不使用用户的 UC 账号，不向语雀、Gitee 发送网盘凭据，也不会生成下载任务。文件由客户端使用站点返回的下载参数直连百度读取。解析页与分享页均可切换为“账号下载”；公益站有独立的服务限制和隐私政策。


账号凭据、保存的密码和应用状态使用项目已有的本地加密存储。加密备份由用户主动导出，需要自行保管备份文件与密码。备份即使加密也不应放入 GitHub、公开 Issue 或 PR。

设备互联在手机端由用户手动开启，在电脑端进入页面时开启，通过局域网发现设备并直接传输所选文件、文件名和主动发送的文字、链接，不经过中转服务器。设备连接使用临时连接码，文件分享链接带随机凭据；持有链接且位于同一局域网的设备可下载对应文件。连接使用局域网 HTTP，请在可信网络内使用，分享结束后可主动关闭；收件箱保存在本地加密状态中。

手机点击“扫码连接”时才请求相机权限，二维码在本机识别，不保存或上传相机画面。连接二维码包含局域网地址、设备标识和本次临时连接码，关闭互联后失效；扫码配对复用现有设备连接流程，文件分享二维码先显示待接收文件，由用户选择下载。

故障日志在本机记录和轮换，由用户主动导出；应用不会自动把诊断 ZIP 上传至项目仓库。日志脱敏不能代替人工检查，反馈时应清理 Cookie、Token、账号、真实文件名、分享链接和本机路径。


启用远程配置的构建会访问构建者设置的 HTTPS 地址，用于公告、平台可用性、帮助说明和更新信息。配置取得后按内容处理，revision 和 ID 不作为必须递增的采用条件。

只有主地址访问失败时，才查询配置的 GitHub 仓库正式 Releases；预发布版和草稿不会提示为正式更新。社区构建默认不配置这些地址。配置服务、GitHub、下载镜像或 CDN 可以获知正常 HTTP 请求包含的网络信息，例如 IP 地址与 User-Agent；应用不会将网盘登录凭据附加到这些配置请求。

BT 功能会连接 tracker、DHT 和对等节点，参与的节点可能看到本机的网络地址。下载时会交换已校验的分片，上传默认上限 512 KiB/s，可在下载设置修改或设为不限速。近期成功连接的节点和 DHT 引导节点保存在现有加密数据库中，数量与有效期有限；新增公共 Tracker 会在后台检查可用性，私有种子不添加公共 Tracker。同种子连续文件完成后最多保留连接 30 秒，旧文件访问立即关闭，暂停和退出停止该任务的数据传输。媒体原生依赖在构建时下载；系统没有可用字幕字体时，应用可能按需下载已固定散列的 Noto Sans SC 字体。

ED2K 下载在用户开始或继续任务时连接 eDonkey 服务器、Kad 和文件来源节点。找源会提交文件的 ED2K 哈希与大小；共享时节点可能收到文件名、已校验的分片和本机网络地址，上传上限 128 KiB/s。默认尝试本地路由器端口映射以改善连接性，受运营商 NAT、防火墙与来源在线状态影响。暂停、任务收尾和退出会停止该任务的网络与写入；文件内容直接在节点与用户设备间传输，不发送网盘账号凭据，不经过应用取链服务器。节点、网络身份、信用记录和分片断点保存在既有本地加密数据库中，删除任务同时移除分片断点。


Android 版本内置友盟+移动统计 SDK，保留当前默认启用及既有授权状态的处理方式，统计应用启动、活跃设备和前台使用时长。当前依赖版本见 `android/gradle/libs.versions.toml`；公开构建也保留 SDK。

统计服务可能处理设备标识符（如 Android ID、OAID、广告标识符）、设备型号、系统和应用版本、网络类型、IP 地址及应用使用统计。应用关闭了 SDK 的 IMEI、IMSI、ICCID、Wi-Fi MAC 和应用列表采集，以及 SDK 的自动崩溃捕获。

应用没有向统计接口提交网盘账号、密码、Cookie、分享链接、文件名或播放内容。统计 SDK 自身的数据处理规则见 [友盟隐私政策](https://www.umeng.com/page/policy)。服务提供方为友盟同欣（北京）科技有限公司、北京锐讯灵通科技有限公司。Windows 未接入该 Android SDK。
