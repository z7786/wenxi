# 文析助手文档

文析助手支持 Android 和 Windows，并提供 iOS / iPadOS 与 macOS 测试包；接入 17 个网盘与 GitHub 文件源，提供链接与口令解析、多账号文件管理、搜索、上传下载、在线播放和设备互联，也支持自定义主题与背景。

功能介绍见 [项目 README](../README.md)，高清宣传图与单页原图见 [手机界面](../README.md#手机界面) 和 [电脑端界面](../README.md#电脑端界面)。以下为持续维护的说明入口；日期命名的审计与复测记录只说明当时状态，使用前需对照当前代码。
