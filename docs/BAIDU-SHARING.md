# 百度文件分享修复

2026-11-15，代码已修复，尚未编译或上传。

## 原因与行为

使用 logs 最新明文备份中的百度账号验证，登录与个人文件列表正常。当前 connector 使用 Android 分享接口 `POST /share/pset`，携带 `path_list` 与 `schannel=4`。提取码为空时，单文件、多文件、文件夹均返回 HTTP 200、`errno=2`；同一测试文件填写四位提取码后均创建成功，游客可以重新打开。

另外用测试文件验证 `schannel=0`，省略或留空 `pwd` 均返回 `errno=115`；保持 `schannel=4` 并省略 `pwd` 仍返回 `errno=2`。以上是该备份账号与当前接口的实测结果，不代表所有百度接口均采用相同规则。

修复后，提取码留空或仅含空白时，在发起创建请求前生成四位随机字母数字码。手动输入会去除首尾空白并校验四位字母或数字，保留大小写。生成或手填的提取码均进入 `ShareCreation`，复制文本包含对应的提取码。

分享弹窗提示“提取码（留空自动生成）”。有效期与 App 鉴权沿用原协议，创建仍只提交一次。日志补充 HTTP 状态、业务码、选择数量、文件夹数量、有效期与提取码来源，不记录账号凭据、文件路径、实际提取码或生成链接。
