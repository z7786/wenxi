# 百度账号下载分流

普通文件按已知字节大小自动选择取链接口，无需新增设置。300 MB 沿用文件列表的二进制单位，即 314,572,800 字节。

| 文件 | 首选路线 | 失败回退 |
| --- | --- | --- |
| 非视频，大小大于 0 且小于 300 MB | 设备内置预览 | 原服务器直链接口，再保留原本的本地预览及普通下载回退 |
| 非视频，正好 300 MB、较大或大小未知 | 原服务器直链接口 | 原本的设备内置预览及普通下载回退 |
| 视频 | 原在线播放 App/DLNA 取链 | 原视频播放流程 |

本地预览和服务器取链都使用当前 App 账号；登录失效仍提示重新登录，取消请求及账号变更会阻止后续路线和晚到的链接。优先路线不消耗下载准备的读取重试预算，最终本地回退仍使用原预算。服务器返回直链后继续校验 CDN 可读取性，并保持对应请求头。

分享普通文件仍按现有规则创建并确认临时副本，再用副本的真实大小、路径和文件 ID 分流；恢复任务复用已确认的副本和清理记录。公益解析独立于账号路线。

相关实现为 `lib/data/providers/baidu.dart`、`baidu_download_resolver.dart` 和 `baidu_local_preview.dart`。本次相关百度回归共 182 项通过，涉及文件的 Dart 静态分析无问题；验证为协议与流程测试，尚未进行新的真实账号测速或编译安装包。

账号下载提示保留风控说明，并注明“因不可抗力因素，视频以外，下载 300MB 以上的普通文件会限速。大文件恢复下载时间待定”。首次显示需等待 10 秒，倒计时期间取消、继续下载、不再显示及返回关闭均禁用；读完并关闭后保存 `baiduDownloadNoticeRead`，以后显示无需再等待。旧版选择“不再显示”但尚未读过新版提示时，更新后仍显示新版说明一次，读完后保留原来的“不再显示”选择；提前退出不标记已读。公益解析仍沿用独立通道，不显示账号下载提示。
