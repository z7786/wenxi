# 百度账号下载取链

账号下载统一使用设备内置接口，无需取链服务配置。文件大小不再决定取链路线，包括小文件、300 MB 边界、大文件和大小未知的文件。

| 文件 | 取链路线 | 失败处理 |
| --- | --- | --- |
| 账号普通文件 | 设备内置预览，直接请求百度官方接口 | 依次尝试百度普通下载接口、文件元数据取链；失败返回错误 |
| 账号视频 | 原在线播放 App/DLNA 取链 | 沿用原视频播放流程 |
| 显式选择公益解析的分享 | 用户所选公益解析通道 | 沿用该独立通道的规则 |

内置取链使用当前账号与安装标识，读取请求沿用下载准备阶段的有界重试预算。登录失效仍提示重新登录，取消及账号变更会阻止后续请求和晚到的链接。内置预览失败后不再请求第三方中转，也不再为中转地址执行 CDN 探测。

分享普通文件仍创建并确认临时副本，再使用副本的路径与文件 ID 取链；恢复任务复用已确认的副本和清理记录。旧任务的 `baidu_direct` 下载参数仍可被读取，重新取链时改走内置接口。公益解析是独立的显式选择，不作为账号下载失败后的回退。

已删除中转客户端及配置模板。构建脚本不再读取本机 `.local/baidu-api.defines.json`；CI 忽略旧 Secret 中的同名条目，不要求先迁移 Secret，也不将其中的参数写入新构建。

账号下载提示保留风控说明，并注明“因不可抗力因素，视频以外，下载 300MB 以上的普通文件会限速。大文件恢复下载时间待定”。首次显示需等待 10 秒，倒计时期间取消、继续下载、不再显示及返回关闭均禁用；读完并关闭后保存 `baiduDownloadNoticeRead`，以后显示无需再等待。旧版选择“不再显示”但尚未读过新版提示时，更新后仍显示新版说明一次，读完后保留原来的“不再显示”选择；提前退出不标记已读。公益解析仍沿用独立通道，不显示账号下载提示。

实现位于 `lib/data/providers/baidu.dart`、`baidu_download_resolver.dart`、`baidu_local_preview.dart`，取链结果类型位于 `baidu_resolved_link.dart`。回归验证包含所有大小的官方请求路径、预览/普通下载/元数据回退、登录失效、取消、账号变化、读取重试、分享恢复和构建配置兼容。实际运行结果保存在本机 `.local/verification/`，协议测试不代表真实账号速度或平台安装包已验证。
