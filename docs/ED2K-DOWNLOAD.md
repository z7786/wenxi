# ED2K 文件下载

在解析页粘贴 `ed2k://|file|文件名|大小|32位哈希|/`，识别后添加下载；也可以从下载管理的“新建下载”粘贴链接。支持中文、编码文件名，以及链接中的 AICH、分片哈希与 IP 来源扩展。只支持文件链接，服务器、搜索等 ED2K 命令不会作为文件下载。

任务沿用现有队列、保存目录、空间检查、暂停、继续、删除和后台传输。下载列表显示查找来源、等待排队、分片下载及校验状态，详情显示传输来源 / 已知来源。没有来源时保持等待；复制链接并不代表存在在线来源，公网速度取决于来源、排队、NAT 与网络。同一时间执行一个 ED2K 任务，任务内部会使用多个来源；HTTP / BT 按原队列并行。

内核使用服务器、Kad 和明确链接来源找源，完成前校验 eMule 分片 MD4，支持 AICH 恢复。最大文件 256 GiB。暂停和重启保留已写入分片；同一文件已有未完成任务时继续原任务，避免共享哈希对应的断点被替换。暂停后停止写盘；重新打开安卓文件时重新绑定授权，完成后关闭原生句柄再保存或发布。

下载期间按 P2P 协议上传已校验的分片，上限为 128 KiB/s；暂停、退出以及完成后的收尾停止传输。ED2K 不使用 HTTP 请求头、HTTP 分段线程或网盘取链接口。内核网络在首次 ED2K 任务才启动，不延长应用启动的接口等待。

源码位于 `native/gopeed/internal/ed2kcore`，通过 `internal/protocol/ed2k` 接入 Gopeed；支持 Android 与 Windows x64 / ARM64。更新后必须重建原生组件，旧原生组件会提示安装完整新版。安卓构建使用 `tool/build-android.ps1 -RebuildNative`；Windows 构建脚本会重建对应架构 helper。许可见应用许可证页与 `assets/licenses/Kelpie-*`。
