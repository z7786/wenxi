# 液态玻璃

默认「液态玻璃」主题参考 [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass/tree/65ab177e90e5c1d8c62e70cf7755841982da65f6) 的 Backdrop 和 LiquidBottomTabs 示例。保留原有主题模式、配色、导航目的地与隐藏资源入口设置；原「通透」设置仍以 `clear` 保存，已有用户自动采用新效果。「磨砂」和「实色」仍可在「我的 → 主题与外观 → 玻璃效果」中选择。

底栏采用 40% 材质底色、8 像素模糊及 24 像素边缘透镜，使用圆角距离场计算边缘法线和圆弧位移。按下和拖动时选中透镜增强折射、高光与少量色散；长按滑动透镜放大到约 78/56，松手弹回。透镜在图标之后绘制，能折射当前页面及导航内容。点击、横向拖动、长按滑动、取消、键盘和无障碍仍复用现有导航行为。

资源首页与搜索结果页的搜索框，以及手机首页的解析、BT 按钮共用玻璃材质。文字与输入框保持清晰，按钮沿用原有回调、禁用状态、焦点和点击面积。搜索结果分批检测及浏览时保持位置的行为继续保留。

页面内操作采用较轻的边缘折射和高光，与悬浮底栏区分层次。解析按钮统一为 60 像素最小高度、16 像素圆角，BT 使用主题浅色底；禁用状态跟随主题。资源首页和结果页使用 `ResourceSearchBar` 统一间距、字体和 48 像素搜索按钮，搜索框采用细描边、不加外阴影，大字体时输入与操作分行。按钮背景传递原尺寸约束，保持内容居中。

`LiquidGlassSurface` 使用实时 BackdropFilter，不逐帧截图或读取 CPU 像素。各材质仅持有自身着色器实例，共享已编译的 FragmentProgram；静止时没有循环动画。色散限制为三次纹理采样。启用 Impeller 的 Android 使用 GLSL 透镜，其他渲染器自动采用模糊与边缘高光；高对比度和实色模式关闭滤镜，系统减少动画时不播放放大动效。

实现：`lib/ui/liquid_glass.dart`、`lib/ui/liquid_bottom_navigation.dart` 和 `assets/shaders/liquid_glass.frag`。上游许可见 `assets/licenses/AndroidLiquidGlass-LICENSE.txt`，移植差异见第三方组件声明。

验证：玻璃实色/高对比度、明暗主题、按钮点击和禁用、拖动取消、RTL、大字体、传输角标及搜索滚动使用 Flutter 测试；页面图片使用本机字体渲染。软件渲染截图只能验证模糊回退与布局，真实折射效果取决于设备 Impeller/GPU 支持。
