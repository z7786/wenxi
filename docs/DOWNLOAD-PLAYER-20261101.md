# 下载与外部播放器调整

百度账号下载提示改为风控与批量下载风险提示，保留取消、不再显示、继续下载的流程。

百度账号预览线路不再强制单线程，默认 8 线程，支持 1–512 线程及跟随全局设置。账号直链保持默认 3、最多 8 线程；公益解析保持默认 64。升级时仅迁移旧预览/普通账号单线程暂停任务，保留断点，后续手动选择 1 线程仍有效。预览 CDN 每个 HTTP 请求最多 8 MiB，多线程与尾段协作仍保持文件校验和断点续传。

原生下载速度按实际单调时间和最近 5 秒采样计算，不再将固定刷新休眠当成完整采样时间。暂停/失败/完成速度归零，恢复时重新建立基线。BT 按各选中文件的新增数据写入计数，排除本地缓存校验和同一种子其他任务的数据；下载页总速度仅累加活动任务。

Windows 播放工具栏和播放设置中的“第三方播放器”可选择本机 exe。成功启动后记住程序路径；再次打开可复用、取消或选择其他程序。程序及播放地址通过独立进程参数传入，不使用 shell。远程视频沿用本机 loopback 转发，必要的 Cookie/请求头由应用处理；在线播放期间需保留播放器页面。通用播放器接口只传入播放地址，是否自动恢复进度由外部播放器决定。

构建产物为 Android ARM64 签名 APK、Windows x64 和 Windows ARM64 安装包。Windows ARM64 使用独立 SDK 交叉构建，所有运行库与 AOT 快照检查对应架构；当前主机无法验证 ARM64 真机播放。
