# 播放性能修复清单（2026-11-11）

本轮按用户清单实施 1–12 项。提供的日志统计作为排查依据，没有重新复核全部原始日志，也没有真机性能测量。D 组音频输出和 rotate 滤镜问题不在本次范围。

## 实现

| 项目 | 行为与边界 |
| --- | --- |
| 1 缓冲状态 | 等待实际播放进度前进，首帧、拖动落点、暂停预览都不代表恢复。起播/拖动使用 2 秒 × 倍速；真实断流按次数为 8/10/12 秒 × 倍速。拖动前更新原生阈值，缓冲闪动不重复计数。 |
| 2 分片起步 | 新媒体请求从 512 KiB 起，每 8 片扩大到 1/2 MiB，再到用户设定上限（默认 4 MiB）；拖动重新起步。保留精确字节边界、元数据优先、部分续读、缓存复用与总内存预算。小于等于 512 KiB 的下载缓存分片沿用原大小。 |
| 3 交替读取 | 连续三次远近交替才启用短窗口，单次文件尾探测不足以触发。拖动重置判断。缓冲中或吞吐低于所需码率的 1.2 倍时放宽窗口，仍受连接/字节预算限制；扩大后不来回震荡。 |
| 4 属性采样 | 编码与像素格式按轨道/格式缓存；硬解、帧率、掉帧和音画差每 10 秒采样。传输调节与无输出看门狗保留 2 秒周期。同步 FFI 读取之间让出事件循环。 |
| 5 字幕写入 | 控制栏显隐只提交目标位置；逐属性去重，位置变化通常只写 sub-pos。Flutter 字幕保留动画。 |
| 6 进度通知 | 位置/缓冲进度最多每 250 ms 通知一次；内部状态与指标保持最新。暂停、播放、缓冲状态、错误立即通知。 |
| 7 UI 诊断 | 前台播放且日志开启时，30 秒汇总 build/raster 最大耗时、超屏幕帧预算比例与 1 秒定时器延迟。标记 debug/profile/release，退出注销回调与定时器。 |
| 8 Android 硬解 | 优先 mediacodec,mediacodec-copy，模拟器保留软解。无输出看门狗命中且当前为 mediacodec 时，先尝试拷贝硬解。新增持久化“兼容硬解模式”处理不能自动识别的绿屏/黑屏。 |
| 9 持续掉帧 | 连续两个 5–20 秒窗口、每窗至少丢 10 帧且输出丢帧率 ≥5%，只降级一次：渲染尺寸降至原目标 75%，bilinear 缩放、关闭 deband。暂停、缓冲、拖动、后台和计数复位打断判断。保持硬解、片源和倍速，不自动把 4K 转软解。 |
| 10 Android 纹理 | vendor media_kit_video 2.0.1，实现 setSize。按视口物理像素、片源比例和放大计算输出；合并 200 ms 布局变化，重配 VO 但不额外 seek。同一 Surface 复用 JNI 引用，替换/清理时延迟释放。 |
| 11 桌面渲染 | Windows/macOS/Linux 使用相同尺寸策略调用 setSize，不超过片源尺寸。修复插件视频参数更新覆盖自定义尺寸。截图继续使用 mpv 源帧路径。 |
| 12 代理 isolate | HTTP、校验、分片内存和 socket 转发在 worker。下载租约回调通过消息调用，缓存数据用 TransferableTypedData；每 500 ms 发送统计。缓存缩减收到确认后才增加 mpv 缓存。停止关闭连接，超时终止 worker。 |

## 指标与回退

outputDroppedFrames 是 mpv 输出丢帧；uiOverBudgetRatio 是 Flutter 已报告帧中超预算比例，不能当成视频呈现掉帧率。静态画面可能没有 Flutter 帧样本。eventLoopMaxDelayMs 提示线程阻塞或调度延迟，不能单独证明原因。

零拷贝初始化失败可按 mpv 列表回退。颜色异常或“mpv 报有输出、实际画面黑屏”不能可靠自动检测，可手动开启“兼容硬解模式”，仍使用硬件解码。原有软解开关和有界恢复继续可用。

降级只减少渲染工作，不减少网络码率或解码像素数。缩小渲染可能影响字幕边缘质量；HDR 也需真机检查。没有宣称提速、节电或掉帧改善百分比。

## 验证

- 开工前 9 个相关测试文件 178 项通过。
- 策略/Range/worker/UI 指标和进度通知共 100 项通过，覆盖渐进分片、非对齐拖动、大缓存块复用、暂停、字节预算、连接上限、错误与关闭；worker 确认拖动状态后才向 mpv 发 seek，避免跨线程顺序竞争。
- 播放器恢复与界面回归 192 项通过。
- Windows 真实 libmpv 播放/恢复 25 项通过，下载播放与原生字幕另 9 项通过。
- 新增原生属性与 Android Dart 控制器测试 3 项通过：真实 mpv handle、模拟平台消息，验证 VO 顺序、尺寸去重、不额外 seek、模拟器回退和字幕属性去重。
- Android Robolectric 21 项通过，含 Surface 复用、重复清理、替换与 JNI 引用释放。生产 Java/Kotlin 和 Flutter debug 编译成功。
- UI 诊断测试覆盖 120 Hz 帧预算、日志开关、暂停和销毁清理。
- 相关 Dart 生产代码与新增测试静态检查通过；原始插件平台代码另做针对性检查。

没有 Android 真机或 macOS/Linux 实机渲染验证。发布前需在反馈机型对照同一片源检查起播、多次拖动、4K60 HEVC、HDR、旋转、字幕、横竖屏、放大、后台恢复、画中画与长时间播放。使用 profile/release，不能用 debug 帧耗时估算发布版收益。

参考：mpv 手册 hwdec、Android GPU context 源码、Flutter SchedulerBinding.addTimingsCallback / FrameTiming。本次没有更换 libmpv 二进制。
