# 播放器屏显

入口：播放器“更多 → 屏显设置”，电视版也从播放设置进入。

“开启屏显”默认关闭。时间、网速、分辨率、进度、标题、播放参数、媒体信息各有独立开关，选择全局保存，切集和重新打开播放器后保留；重置控制栏布局不会清空屏显选择。文字样式可选“黑色描边”和“半透明底色”，默认黑色描边，不铺背景，旧配置也采用该默认值；样式选择同样全局保存并立即生效。

画面不显示“时间”“网速”“分辨率”等字段标签，直接显示内容及必要单位，例如 `20:20:22`、`2.00 MB/s`、`1920 × 1080`、`02:21 / 10:00 · 23.5%`。缓冲显示秒数（`90.0 s`），丢帧数按解码 / 输出顺序显示（`2 / 3 帧`），缺失一项使用 `--`。标题与编码信息保留实际内容。

点击画面展开播放控制栏时立即隐藏屏显，控制栏手动收起或自动隐藏后恢复；初始控制栏显示期间也隐藏。锁定播放时保留屏显，解锁唤出控制栏后隐藏。隐藏期间停止屏显刷新和网速监测，不改变已保存的屏显开关或样式。

## 位置

| 位置 | 内容 |
| --- | --- |
| 左上 | 文件标题、当前视频显示分辨率（包含旋转和像素宽高比） |
| 右上 | 系统时间 |
| 左下 | 视频编码/帧率/像素格式/轨道码率、音频编码/采样率/声道/码率、已播放时间/总时长/百分比 |
| 右下 | 倍速/解码方式、缓冲、解码与输出丢帧数、实际接收网速 |

四角固定在整个播放器屏幕的安全区域内，包括视频周围的黑边；宽高比、填充方式、缩放、平移不会移动屏显，控制栏收起或锁定后恢复在相同位置。手机保留刘海等安全边距，电视版保留安全边距。黑色描边使用独立描边层和文字填充层，避免遮挡画面，并排除描边层的重复朗读；半透明底色可在设置中切换。长标题和参数受各自区域宽度约束；播放参数拆成短行，避免一整行跨过画面。窄屏允许换行并在必要时缩小信息区，屏显不接收触摸或遥控焦点，画中画和布局编辑时隐藏。

Android 屏显独立使用刘海、挖孔等物理遮挡边距，不沿用控制栏保留的状态栏、导航栏空间，也不累积旋转前的边距；原生边距尚未到达或旧桥接未提供时使用当前 Flutter 边距。手机信息区距安全边缘 12 个逻辑像素，视频居中或留黑边不会额外增加屏显边距。

## 刷新与数据

- 独立屏显区域每 250 ms 检查缓存数据，仅在显示内容变化时重绘，不通知播放器或重建视频。
- 系统时间按秒变化，进度最多每 250 ms 更新，分段播放网速按累计接收字节在至少 1 秒的真实时间窗口内计算，计数器复位或切换后端后重新测量。
- 原始连接/HLS/BT 使用 mpv `cache-speed`，启用网速屏显时才在已有 2 秒性能采样中读取一次，并在读取前让出事件循环。它是缓存与下层之间的 I/O 接收速度，不是整个设备的总网速。边下边播使用对应下载任务的速度。
- 本地显示“本地播放”；未提供的数据显示“待获取”，不把媒体码率当成网速。投屏时不显示手机后端的过期数据，并说明电视端解码信息不可获取。
- 解码信息复用既有低频诊断缓存，轨道信息来自播放器状态；不显示来源 URL、请求头或账号信息。
- 进入后台、关闭网速项目或销毁屏显后停止网速监测；返回前台恢复。
