# 播放器屏显

入口：播放器“更多 → 屏显设置”，电视版也从播放设置进入。

“开启屏显”默认关闭。时间、网速、分辨率、进度、标题、播放参数、媒体信息各有独立开关，选择全局保存，切集和重新打开播放器后保留；重置控制栏布局不会清空屏显选择。

## 位置

| 位置 | 内容 |
| --- | --- |
| 左上 | 文件标题 |
| 右上 | 系统时间、实际接收网速 |
| 左下 | 视频编码/帧率/像素格式/轨道码率、音频编码/采样率/声道/码率、已播放时间/总时长/百分比 |
| 右下 | 当前视频显示分辨率（包含旋转和像素宽高比）、倍速/解码方式、缓冲、解码与输出丢帧数 |

四角按锁屏时实际可见的视频画面定位，使用与视频相同的宽高比、填充方式、缩放和平移，再与设备安全区域求交。控制栏显隐和锁定/解锁不会移动屏显；电视版保留安全边距。四个信息区使用轻量半透明黑底，长标题和参数受各自区域宽度约束；播放参数拆成短行，避免一整行跨过画面。窄屏允许换行并在必要时缩小信息区，屏显不接收触摸或遥控焦点，画中画和布局编辑时隐藏。

## 刷新与数据

- 独立屏显区域每 250 ms 检查缓存数据，仅在显示内容变化时重绘，不通知播放器或重建视频。
- 系统时间按秒变化，进度最多每 250 ms 更新，分段播放网速按累计接收字节在至少 1 秒的真实时间窗口内计算，计数器复位或切换后端后重新测量。
- 原始连接/HLS/BT 使用 mpv `cache-speed`，启用网速屏显时才在已有 2 秒性能采样中读取一次，并在读取前让出事件循环。它是缓存与下层之间的 I/O 接收速度，不是整个设备的总网速。边下边播使用对应下载任务的速度。
- 本地显示“本地播放”；未提供的数据显示“待获取”，不把媒体码率当成网速。投屏时不显示手机后端的过期数据，并说明电视端解码信息不可获取。
- 解码信息复用既有低频诊断缓存，轨道信息来自播放器状态；不显示来源 URL、请求头或账号信息。
- 进入后台、关闭网速项目或销毁屏显后停止网速监测；返回前台恢复。

测试覆盖配置迁移与全局保存、所有项目开关、四角位置、窄屏/横屏/电视界面、画中画、局部刷新、后台恢复、网速计数窗口，以及真实 libmpv 解码和直连 HLS 网速属性。自动测试不能代替 Android 真机性能复核。

mpv 属性说明：https://mpv.io/manual/stable/#command-interface-cache-speed
