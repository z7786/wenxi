# 跨盘传输

在文件菜单选择跨盘传输后，任务进入「传输 → 上传」。目标支持秒传且来源有可信 MD5 时先请求秒传，未命中则下载原文件后上传；目前 MD5 目标为 123、天翼和光鸭。秒传是否命中由网盘接口决定。

跨盘传输默认同时处理 3 个文件，上传页面直接显示「同时处理数」下拉选择，提供 1、2、3、5、8 和自定义输入，允许 1–8 个；也可在「我的 → 下载设置 → 同时跨盘任务数」修改。这是独立于普通下载任务数的设置。一次选择多个文件或整个文件夹时，扫描后的文件也进入并发队列，不再等上一文件上传结束才下载下一文件。多个跨盘批次共用文件并发上限，批次之间轮流获取空闲名额，批次内按文件顺序排队；同时扫描的批次也不超过此上限。提高上限立即补充文件，降低上限保留已开始的文件，结束后按新上限调度。各批次使用独立取消范围，继续和删除记录会等待该批次全部文件的旧执行结束；账号失效、授权取消和限流会停止该批次的其他文件，普通文件错误不阻止后续文件。相同账号、空间、目录内的同名文件和文件夹共用写入锁，处理前重新读取目标，中转下载共同预留剩余缓存空间；同一批次的目录读取与创建复用正在执行的请求，移动数据确认只提示一次。

普通文件上传和文件夹内的文件共用最多 2 个文件名额，跨盘传输仍沿用上述独立的同时处理数。夸克/UC、阿里、百度、123、天翼以及通用 OSS/S3 的独立分片默认每文件并发 3 片；普通上传、跨盘上传及直接表单上传共用最多 6 个发送名额，授权与签名也在分片名额内执行，避免大批任务同时发起请求。移动、联通和微云等需要顺序的上传协议保持原顺序。同一文件任一分片失败后取消其他在途分片，等待它们结束，不发送最终合并；乱序完成仍按分片序号合并。普通上传、目录创建与跨盘写入共用同名目标锁，取得名额后重新检查目标，取消等待不会继续创建文件。

夸克/UC 的整文件 MD5 与 SHA-1、百度的整文件/分片/前缀 MD5、天翼的整文件与分片 MD5 在一次读取中计算。大于 256 KiB 的摘要计算交给后台 isolate，全应用最多 2 个；文件权限和来源校验仍在调用侧执行，每次最多向线程传递 512 KiB，处理后再继续读取，不把整个文件缓存进内存。跨盘中转已验证的整文件摘要继续复用，缓存恢复时仍核对内容。网盘返回可信、完整的最终保存回执时直接核对文件标识、名称、大小和可比摘要；缺少字段继续读取目录，不一致则报错并保留已收到的文件标识供恢复确认。

中转下载与上传分别显示进度，批次速度汇总各个正在传输的文件。中转下载复用普通下载的 Gopeed 内核，沿用来源网盘及下载路线的连接数、限速、重试和网盘连接限制；小文件或不支持 Range 的来源由内核减少连接或单连接下载。内核保留足够的运行名额，由普通下载与跨盘管理器分别限制并发，不再被固定 3 个内核任务的上限拦住。每个文件开始下载时读取配置，已建立的断点保留原配置。下载中断后保留分片，继续时核对来源和远端文件身份；身份变化或无法可靠续传时重新下载。

进度按实际字节计算，不按已处理文件数平均。扫描结束后，待判断和排队的文件就计入下载、上传阶段的总量，后续开始传输不会扩大分母；已确认秒传和同名跳过的文件不计入中转流量。同名跳过单独统计，全部跳过显示「全部已跳过」，失败文件保留已传字节而不算成功。下载、上传速度分别汇总对应阶段的活动文件，首个续传快照中的已有字节不计为新流量。文件大小未知时暂不显示百分比。

中转文件校验期间显示「校验中」，上传预处理显示「准备中」，请求目标网盘确认保存时显示「确认中」。下载只有通过校验才显示完成，上传只有返回已确认的保存结果才显示完成；确认前进度最多为 99%。总进度按文件大小加权，下载后上传文件的下载与上传各占一半，已确认秒传文件计为完成。旧任务记录可继续恢复，下载进度保留；重新上传时仅重置上传阶段，缓存身份或内容校验不通过时重新下载并重置相应进度。

下载完成后校验文件，同时计算 MD5 和 SHA-1，上传复用这些结果。上传失败时保留完整的中转文件；继续任务会先核对来源、目标和缓存校验值。上传和秒传请求发送前保存待确认状态及真实目标目录，已收到的文件标识在取消或目录确认失败前保存。恢复时先多次读取原目录，按回执标识或同名、大小与 MD5/SHA-1 核对，已确认保存就直接完成；有同名项目但无法证明是本次上传时单独跳过，避免再次写入。若请求可能已到达网盘且仍查不到结果，显示「上次上传结果仍待确认」，保留进度和缓存，后续继续仍只确认，不自动重传；其他批次也不能重复提交同名未确认文件。上传前校验、连接建立和临时授权失败，未合并的分片（包括最后一片）仍可重试；能直接保存文件的请求或最终合并结果不确定时先确认。临时分片的初始化和清理不算保存文件。

尚未提交到目标时，缓存损坏或丢失会重新下载。校验失败的文件会清理。下载目录仍为应用中转缓存，单个文件下载完成后再上传，多个跨盘任务可同时推进。旧版本已提交但中断的记录按待确认恢复，不清除原回执；确认期间上传进度显示「确认中」，不产生新的流量。

删除任务记录会清理该任务的中转文件。「清理失败跨盘传输」批量删除已停止且仍可重试的任务和缓存，保留正在传输的任务及目标网盘中的文件。确认前固定本次任务范围，实际清理前重新核对状态，跳过已恢复的任务，不加入后来失败的任务；没有可清理任务时直接提示。

清理弹窗显示总数、已处理数量，以及等待旧执行停止或删除中转文件的阶段。每条缓存删除且记录保存成功后立即更新列表；单条失败时保留记录并继续其他条目，结束后显示成功数量和失败原因。记录保存失败也保留原任务，后续可再次清理。取消等待不会删除仍在使用的缓存；取消时若一条删除已开始，先完成该条的文件清理和记录保存，不再开始后续条目。诊断记录包括清理数量、取消状态及各条错误，不包含网盘链接或凭据。
