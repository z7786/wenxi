# Android 长播复测：2.3.5+236

此包供复现 `看视频闪退*.zip` 中的问题，没有故障机型的真机验证结论。先导出旧版日志，安装测试包后再确认新播放会话的 `session.start.fields.version` 是 `2.3.5+236`。系统退出历史也会列出旧版记录，只统计本次测试开始之后的主进程异常；手动上滑清理、覆盖安装或 WebView 子进程退出不计入。

| 设备 | 操作 | 记录与判断 |
| --- | --- | --- |
| 荣耀 ROD2-W09、vivo PA2455 | 保留原硬解设置，用之前触发问题的片源连续播放至少两小时。记录开始时间；分段测试触摸进度条、拖动、切集和退后台再返回。 | 记下无响应时的最后一次操作和北京时间。重开后导出应用日志，检查新会话是否出现输入分发超时、主线程是否仍在 `mpv_get_property_string` 等待。只出现取帧告警不算复现。 |
| 荣耀 VER-AN10 | 使用之前闪退的本地 H.264 文件，保持相同起点、倍率和操作，分别测试默认硬解、兼容硬解、关闭硬解；一次只改一项。 | 记录每次持续时间、结果和 `hwdecCurrent`。停播但应用还能操作时，查看 `player.terminal_failure` 的 `origin=mediacodec_released`，核对进度保留、没有自动重开硬解，并尝试关闭硬解继续。若退回桌面，检查是否又出现 Codec2 / `native_handle_clone` 的 `SIGSEGV`。 |

荣耀 ROD2-W09 上单独的 Binder `SIGABRT` 仍缺少断言正文。如果再现，记下时间，尽快从已授权连接的电脑运行 `adb bugreport playback-bugreport.zip`；在本地取对应进程、时间的 abort message 和崩溃线程栈。系统报告可能含其他应用和个人信息，不要直接公开原件。

回报时附：机型、会话版本、解码设置、片源类型、观看时长、最后操作、具体症状和对应的新日志。长播通过只能说明这轮未复现；一次应用层错误提示也不等于系统崩溃已消除。
