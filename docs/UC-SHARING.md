# UC 文件分享修复

2026-11-15，代码已修复，尚未编译或上传。

## 复现与原因

使用 logs 最新账号备份中的 UC 账号，个人文件列表和临时文本上传正常，创建分享请求却返回 HTTP 500、业务码 15000（`inner error`）。

官网当前网页版本为 `cloud-drive-web/2.21.6`。创建分享调用 `POST /1/clouddrive/share`，其中 `public_search` 使用数字值。项目原来传 JSON 布尔值 `false`；同一账号与测试流程仅将该字段改为数字 `0` 后，创建分享、查询任务和读取分享链接均成功。

修复只将 UC 的 `public_search` 改为 `0`，仍不允许公开搜索。文件选择、标题、有效期、提取码、账号刷新、异步任务轮询和夸克参数保持原协议。

四个测试分享均已取消，临时目录与测试文件已移除，未修改用户原有文件。

`uc_share_creation_test.dart`、`uc_test.dart` 与 `cloud_audit_test.dart` 共 106 项通过。覆盖 UC 请求类型、异步结果、提取码、Cookie 更新、业务拒绝不重复创建，以及夸克原分享参数。修改文件静态分析通过。

实测记录保存在 `.local/uc-share-20261115/`，仅记录接口路径、状态码、响应结构和验证结果，不保存账号凭据或生成的完整分享链接。实测说明协议已恢复；具体文件若受到上游审核限制，仍按接口错误报告。
