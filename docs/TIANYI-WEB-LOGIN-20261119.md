# 天翼网页登录检测等待修复

用户反馈：安卓在天翼官网完成登录后，应用一直停在检测。当前 logs 的最新压缩包记录的是百度视频黑屏，没有本次登录记录，因此未确认用户设备卡住的具体阶段。

检查发现天翼账号身份验证后还会等待容量接口；该请求原本沿用较长的网络超时。网页登录验证、登录后 Cookie 清理也没有整体等待上限。读取不同 Cookie 路径时，串行等待与页面跳转中的 JavaScript 读取会累加延迟。

本次修改：

- 天翼 Cookie 的独立路径并行读取，结果保留账号 API 优先级，并读取 HttpOnly Cookie。网页浏览器绑定单独设 3 秒上限；页面脚本不可用时仍可验证原生 Cookie。
- 天翼单轮网页登录信息读取上限 12 秒、账号验证上限 15 秒。超时释放检测状态，显示重试提示；账号验证超时取消所属请求，不提交迟到结果。
- 身份验证成功后的容量读取最多等待 3 秒，超时取消独立请求，仍保存已验证的账号。常规账号刷新继续读取容量。
- 登录前后 Cookie 清理等待最多 3 秒。登录前清理失败仍阻止打开旧会话；登录后清理失败记录诊断后退出登录页。
- 用轮询编号识别检测状态，页面重建或旧异步回调不能把新的检测锁住。

验证：

- `tianyi_web_login_test.dart`、`web_login_diagnostics_page_test.dart`：62 项通过，包含容量永不返回、验证超时后重试、迟到结果、Cookie 清理回调永不返回、脚本与部分 Cookie 读取不返回。
- 天翼会话、原生登录、账号存储、浏览器 UA、Apple 登录回归：96 项通过。
- 本次修改文件的静态检查通过。

没有连接安卓设备，尚未完成用户设备真实登录复测。本次未编译、发布或上传代码。
