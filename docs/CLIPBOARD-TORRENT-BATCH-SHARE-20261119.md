# 剪贴板、BT 目录和批量分享

## Windows 剪贴板历史

Windows 的 Win+V 选择内容会发送没有扫描码的 Ctrl/V 模拟按键。Flutter 给这些按键分配同一个物理键值，并在中间补发 Ctrl 松开事件，导致输入框收不到正确的粘贴快捷键。上游问题：<https://github.com/flutter/flutter/issues/143997>。

`lib/platform/windows_clipboard_keys.dart` 在 Windows 入口修正这组按键，继续使用系统剪贴板和 Flutter 的原有粘贴操作。保留正常按键和键盘初始化探测事件；序列中断或超时会释放补入的按键，避免 Ctrl 一直处于按下状态。主窗口和独立播放器窗口共用入口。

自动测试覆盖按键修正、普通 Ctrl+V、选区替换、后续输入及中断恢复。仍需在 Windows 系统剪贴板历史窗口中实际点击条目验证；本次没有生成安装包。

## BT 文件目录

磁力和种子文件解析后只显示当前目录的直接子项。点击文件夹进入，返回键和“返回上一级”逐级返回；较深目录提供返回根目录按钮。每个目录记忆滚动位置。

勾选是整个种子的共享状态。文件夹复选框选中其全部后代文件；全选、清空选择和下载仍作用于整个种子。进入或返回文件夹不改变已选文件。

## 单文件批量分享

网盘文件列表选中多项，点击分享，可选择合并分享或单文件批量分享。后者调用已有网盘接口，逐项生成链接，使用文件自身名称以及用户选择的有效期、提取码。蓝奏和城通仅支持单项分享，多选时直接使用逐项分享。

处理过程显示数量和结果，支持单条复制、复制全部及停止。某项失败后继续下一项；停止或账号变化时保留已经创建的链接。没有自动重试分享写请求，避免返回不确定时重复创建。此功能遵循各网盘现有分享能力和限制。

本次相关 128 项测试通过，静态检查无问题。测试使用模拟网盘，没有创建真实公开分享，也没有编译、提交或上传。
