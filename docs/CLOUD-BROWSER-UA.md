# 网盘浏览器 UA 策略

普通桌面浏览器请求共用 `DesktopBrowserUa.builtIn` 的 12 组 Chrome、Edge 和 Firefox UA。
`CloudBrowserUa` 按网盘、账号隔离身份，`BrowserUaJsonHttp` 在现有读取重试层外应用策略。

## 启用范围

| 平台 | 普通浏览器请求 | 保留的专用请求 |
| --- | --- | --- |
| 阿里、光鸭、微云、联通、城通 | API、登录和普通下载 | 缺少 UA 的存储上传请求不补写 UA |
| 蓝奏优享 | API、登录、下载；同步 devModel/devVersion | 签名和加密参数保留原始编码，存储节点请求不修改查询参数 |
| 123 | 普通 Chrome 登录、API、下载 | Dart 分享、转存和跳转探测 UA |
| 移动 139 | 普通桌面请求和下载；同步浏览器设备元数据 | 手机 Chrome 150 分享与口令请求 |
| 天翼 | 普通桌面 API、密码登录和下载 | 手机网页、移动授权和备用下载请求 |

## 身份生命周期

- 每个账号首次使用时随机抽取桌面 UA。旧账号通过账号隔离的 `*.browser_user_agent` 元数据保存身份，不改变认证凭据的修订号。
- 新登录在验证成功后把身份写入凭据的 `browserUserAgent` 字段；失败或取消不会改写旧账号的身份。
- 登录窗口、SSO 弹窗、原生验证码窗口，以及短信发送和验证使用同一个身份。专用手机版登录模板保持原有 UA。
- 分享会话的 `browserUserAgent` 元数据跟随会话序列化。下载准备把实际身份写入 `DownloadSpec.headers`，供分片、播放代理和断点恢复复用。
- 获取新下载链接时可以重新建立解析会话；已签名链接及其分片不会中途换 UA。解析规则提供的下载 UA 不被覆盖。

## 拦截与重试

共享策略只在未登录、明确标记为读取的请求收到可识别的 HTML 浏览器拦截页面时换身份，最多 3 组且不重复。JSON 权限错误、401、空 403、429、已固定的会话和任何修改请求不触发该重试。

已登录账号固定身份；需要登录或安全验证的错误继续由原有网盘分支处理。蓝奏与小飞机继续执行各自已有的 403 分类与恢复机制。

## 验证

- `cloud_browser_ua_test.dart` 覆盖专用 UA 保留、账号隔离、嵌套多账号、重启恢复、登录失败、读取轮换、修改不重放、设备元数据和分享下载一致性。
- 登录与网盘回归覆盖验证码、网页登录弹窗、账户切换、下载恢复和上传。
- 115 本地 HTTP + libmpv 测试验证生成链接时的 UA 与真实媒体请求一致，并覆盖起播、Seek 和过期恢复。
- 未完成所有网盘的真实账号与 Android 真机验证。
