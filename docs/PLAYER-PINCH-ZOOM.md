# 视频双指缩放

播放视频时，在画面上用两根手指向外拉开放大、向内捏合缩小。支持横屏、竖屏和平板，比例范围为 50%～300%，画面中央会显示当前比例。

缩放沿用「画面 → 画面比例与缩放」设置，以画面中心为基准，保留原有水平、垂直偏移。字幕、播放控制和四角屏显不会跟随视频放大或移动。「重置缩放与位置」恢复 100% 和居中显示。

拖动期间即时预览，结束时保存比例；目录记忆启用时，同目录视频及重新打开沿用该比例，其他目录使用各自的设置。进入后台或关闭播放器时保留已调整的比例，切换视频会取消未结束的旧手势，避免覆盖新视频的设置。

第二根手指按下后取消尚未提交的进度预览，结束此前的亮度、音量或临时长按倍速调整。双指操作期间不触发这些单指动作，松开一根手指后继续忽略剩余手指，全部松开才恢复单指手势。第三根手指按下会暂时停止缩放，恢复两指时重新计算距离，避免画面突跳。锁屏、投屏、画中画、外部播放器与纯音频不触发双指缩放。

缩放期间保持手势开始时的渲染尺寸，只改变画面显示比例；松手后再按最终比例更新渲染尺寸，避免每次触摸移动都重建视频输出。

验证使用 `test/player_pinch_zoom_test.dart` 的真实双指触摸事件，覆盖实时预览、范围、画面与字幕/屏显位置、目录记忆、取消和切换视频、手势接管、第三指、锁屏、后台与退出，以及双指松开后立即单击不会误暂停。原有 `test/player_widget_test.dart` 的单指、倍速、画面设置和画中画测试继续通过；未做真机性能测量。
