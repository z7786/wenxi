# 视频双指缩放、旋转与移动

播放视频时，两根手指向外拉开放大、向内捏合缩小；转动两指调整角度，一起拖动移动画面。这三种操作可以同时进行，支持横屏、竖屏和平板，比例范围为 50%～300%，画面中央显示当前比例和非零旋转角度。

手势以两指中点选中的视频位置为基准。调整中，两指中点移动到哪里，原来选中的视频点就跟随到哪里；已经缩放、旋转或移动的画面可以继续调整，到达缩放上下限后仍能平移和旋转。沿用「画面 → 画面比例与缩放」设置，增加角度调节，字幕、播放控制和四角屏显不跟随视频变换。

本次双指手势首次实际调整时，在视频上方显示可点击的「还原屏幕」，3 秒后隐藏，持续移动或替换手指不延长时间。下一次手势再次实际调整时重新显示。点击恢复 100%、居中和 0°，保留播放进度、倍速、画面比例、显示方式及字幕设置；手指未松开时重新计算基准，下一次移动不会跳回还原前的画面。画面设置内保留同名按钮，提示消失后仍能还原。

拖动期间按显示帧合并两指事件，实时预览，结束时一次保存比例、位置和角度；目录记忆启用时，同目录视频及重新打开沿用完整变换，其他目录使用各自设置。旧备份缺少旋转字段时默认为 0°，原比例和位置保留。进入后台或关闭播放器时提交最后一次尚未显示的有效调整；切换视频丢弃旧手势的待显示结果，避免覆盖新视频设置。

第二根手指按下后取消尚未提交的进度预览，结束此前的亮度、音量或临时长按倍速调整。双指操作期间屏蔽单指动作，松开一根手指后继续忽略剩余手指，全部松开才恢复单指手势。第三根手指加入时先提交最后一次预览，再暂停变换，恢复两指时重新计算中点、距离、角度和位置，避免突跳。重叠触点或屏幕尺寸改变后同样重新计算基准。锁屏、投屏、画中画、外部播放器与纯音频不触发双指手势，切集、锁屏、后台、打开设置及画中画时收起提示并取消计时。

手势期间、松手保存及「还原屏幕」均只改变 Flutter 视频显示变换，底层输出按视口尺寸保持稳定，避免松手后重建视频输出而短暂停顿。窗口大小、画中画和视频源变化仍会调整输出尺寸；放大不会额外增加渲染像素。

验证使用 `test/player_pinch_zoom_test.dart` 的真实双指事件和渲染坐标，覆盖非中心锚点、已变换画面再次调整、缩放边界、平移、组合旋转、跨 180° 与整圈旋转、帧合并、末次预览保存、第三指替换、3 秒提示及还原、目录记忆、切集、手势接管、锁屏、后台和退出。`test/player_widget_test.dart` 验证设置内角度预览和保存、完整还原与桌面画中画恢复，原有单指、倍速、字幕和四角屏显测试继续保留；尚未做真机性能测量。
