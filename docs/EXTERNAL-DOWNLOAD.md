# 从外部应用调用下载器

每次接收 HTTP / HTTPS 下载链接后，文析助手会打开确认框，允许修改文件名、请求头和本次线程数（1–512）。点击“添加下载”才会创建任务，线程设置不会修改全局偏好，暂停、继续和重启后保留。实际连接数还取决于文件大小和服务器是否支持分段读取。

## Android

浏览器的“使用其他应用下载”或文本分享菜单中选择 **文析助手下载器**。支持 `ACTION_VIEW` 的 HTTP / HTTPS 地址（可带 MIME 类型）和 `ACTION_SEND` 的文本链接。调用方提供的下载请求头会经校验后传给下载器。

网盘分享链接和磁力链接仍进入对应的解析流程；视频选择“文析助手播放器”时直接进入播放器。

## Windows

安装版注册 `wenxi://download` 调用链接，例如：

```text
wenxi://download?url=https%3A%2F%2Fexample.com%2Fapp.apk&name=app.apk
```

`url` 是完整下载地址，`name` 为可选文件名，两者使用标准 URL 查询参数编码。已启动时会交给原窗口处理；未启动时会先启动软件。安装版和便携目录都可以通过命令行调用：

```powershell
& 'D:\文析助手\asterlink.exe' --download 'https://example.com/app.apk'
```

Windows 浏览器需要支持外部下载器配置或调用上述链接。该入口不修改默认浏览器，也不会接管所有网页链接。

## 百度下载线程

公益解析默认 64 线程，账号预览线路默认 8 线程，均可在下载设置中调整（1–512，也可跟随全局设置）。账号直链默认 3 线程、最多 8 线程。旧的单线程暂停任务升级后按当前设置恢复，保留已下载数据。预览线路每次分段请求仍限制为 8 MiB，以兼容百度 CDN。外部应用直接传入的 HTTP / HTTPS 文件地址使用确认框里的本次线程数。
