# 边下边播

## 普通 HTTP 文件

播放器优先读取下载器公布的已写入区间。每次读取都验证远端身份、区间和实际文件数据，不使用稀疏文件长度判断完成度。分片中存在多个空洞时，只请求各个缺失区间，随后继续读取已下载数据。缓存快照失效或读取不到数据时，按原身份补取，不混入变化后的文件内容。

下载未完成时，播放器持有下载缓存占用。退出播放器会释放占用，下载任务继续运行；显式暂停下载后，可读取已有数据，缺失数据不能继续联网补取。下载完成后，正在播放的占用仍可读缓存，最后一个占用释放后清理下载临时文件。

每次准备、手动重试和自动刷新都检查任务最新状态。已完成时，检查保存文件的可访问性并直接打开本地路径或 Android content URI，保留播放进度。地址刷新期间完成下载时，无论刷新返回新地址还是失败，都优先使用已保存文件。文件缺失或权限失效会给出对应提示。

## 来源网络权限

自定义来源任务的 `DownloadNetworkPolicy` 同时约束播放探测、缺失区间补取、CDN 地址重新解析、内置播放器原始连接回退、外部播放器和电视中转。连接使用权限客户端检查协议、主机、端口和 DNS 公网地址；每次重定向也检查目标，并按策略剥离跨域自定义鉴权头。回到原站时不会恢复已剥离的请求头。

权限拒绝使用不可自动刷新的 `restricted` 错误，不退回未受约束的原地址。内置播放器的非 Range/HLS 回退由受检查的本地中转提供。来源受限的 DASH 和外部直链交接暂不支持，界面提示使用内置播放器或下载完成后播放。

## HLS 功能边界

HLS 下载器写入的合并数据不属于普通 HTTP Range 缓存。已识别的 HLS 任务（清单地址、文件名或已保存的 HLS 状态）显示“在线播放”，详情明确说明“播放与下载独立取流，不复用已下载片段”。播放入口保留，退出后下载继续；已完成后的播放使用保存文件。

当前没有实现本地 HLS 清单及下载片段复用。播放清单与媒体片段产生的独立流量不能当作下载任务进度或下载速度。
